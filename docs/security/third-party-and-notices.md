# Third-party integrations and notices

The toolkit references .NET skills, tools, Codex formats, and TypeSafe's HTTP format; it
does not vendor their implementation source or imply affiliation. Product integration
manifests contain indicative policy and license labels, not a substitute for reviewing
the concrete package or version before redistribution.

Runtime code uses the .NET base class library. Test dependencies are restored separately
and excluded from product source release archives. See the product's canonical
[`THIRD-PARTY-NOTICES.md`](https://github.com/simplexidev/codex-toolkit/blob/develop/v2.0.0/THIRD-PARTY-NOTICES.md)
and [`NOTICE.md`](https://github.com/simplexidev/codex-toolkit/blob/develop/v2.0.0/NOTICE.md).

Upstream status and drift commands report information for review. They do not download,
install, update, or merge third-party code. Confirm current upstream documentation before
adoption.
